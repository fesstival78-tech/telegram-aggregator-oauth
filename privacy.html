Privacy Policy

Last updated: October 30, 2026

About the Application

TelegramAggregatorBackup is a private utility used to back up a personal Telegram automation project.

Google Drive Access

The application uses the Google Drive API with the drive.file permission to create, access, and manage files used for its backups.

Data Storage and Security

Backup archives are encrypted before being uploaded to Google Drive.

Data Sharing

The application does not sell or share Google user data with third parties.

Data Retention

Daily backups are retained for up to 30 days. Version backups may be retained for longer.

Data Deletion

The application owner can delete backup files directly from Google Drive. Google account access can be revoked through Google Account security settings.

Contact

For privacy inquiries, contact the application developer using the support email listed on the Google OAuth consent screen.
